## 6. 남은 Owner 확인 1건 — GA 이벤트 데이터 보관기간

1. https://analytics.google.com 에 gokoreamate 속성 관리 권한이 있는 Google 계정으로 로그인한다.
2. 왼쪽 아래 **톱니바퀴(관리)** → 가운데 **속성** 열에서 gokoreamate 속성(측정 ID 가 G-C0N 으로 시작)을 고른다.
3. **데이터 수집 및 수정** → **데이터 보관** → **이벤트 데이터 보관** 의 값(예: 2개월 / 14개월)을 읽는다. 값만 알려 주면 된다(바꾸지 않아도 된다).
4. 목록에 속성이 보이지 않으면 그 계정에 권한이 없는 것이다 — GA 를 처음 만든 계정으로 다시 로그인한다.

값을 받으면 처리방침 제7·8조와 L1 에 반영한다. 받기 전까지 GA 보관기간은 제7조 마커에 남아 DRAFT 를 유지한다.

Production 적용 승인 요청은 GA 값과 L1~L6 결과가 모인 뒤 런북 D-2(파일·해시)와 D-4(merge 범위)를 붙여 한 번에 올린다.
