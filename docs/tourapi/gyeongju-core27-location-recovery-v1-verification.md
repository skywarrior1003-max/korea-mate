### 이슈-01 (IMPROVEMENT — 주요): VG raw HTML 내장 좌표 우선 활용 명시

**프롬프트의 좌표 확인 우선순위**:
> 4. 기존 KTO contentId를 이용한 공식 상세 API  
> 5. 경주 공식 detail HTML·script·JSON·지도 파라미터의 명시 좌표

**실제**:
- 21건 중 identity bundle에 `kto_content_id = None`인 건: **21/21**
  - 경주 엑스포대공원은 KTO ID 127487이 KTO_RELIABLE_MAP에 있었으나  
    이전 태스크의 normalize_kto_name 버그로 identity bundle에 미등록됨
  - 나머지 20건은 KTO type12 exact match 없음
- 따라서 단계 4 (KTO contentId 상세 API)는 **21건 전원 건너뜀**
- 단계 5 (VG HTML 좌표)에서 **21/21 전량 추출 가능** — 기존 frozen raw 재파싱만으로

**결과**: 프롬프트대로 실행해도 동작하지만, 스크립트가 단계 1~4를 모두 시도한 뒤 단계 5에서 처리된다. 스크립트 설계가 더 복잡해지고 독자가 혼동할 수 있다.

**개선 권고**:

1. 기존 candidate의 검증된 좌표
