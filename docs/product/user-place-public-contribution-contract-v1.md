# 사용자 장소 공개 기여 계약 v1

상태: 확정 (제품 결정)
기록 시점: 2026-08-08
적용 범위: My Places(`user_spots`), 공유, 공개 장소 제안, 관리자 알림

---

## 왜 이 문서가 있나

My Places 는 개인 장소다. 그런데 사용자가 저장한 장소와 여행 기록이 밖으로
공유되고, 그것이 다시 gokoreamate 의 발견·데이터로 돌아오는 흐름은 이 제품의
핵심 루프다.

이 두 가지는 쉽게 뒤섞인다. 뒤섞이는 순간 둘 중 하나가 망가진다.
개인 장소를 공개로 흘려보내면 신뢰를 잃고, 공개 기여 통로를 막으면 데이터가
자라지 않는다. 그래서 경계를 문서로 못 박는다.

이 문서는 구현 범위를 넓히려는 것이 아니다. **나중에 이 방향을 잃지 않기
위한 기록**이다.

---

## 1. 기본값은 개인이다

- `My Places / user_spots` 는 기본적으로 **개인 장소**다.
- 개인 `user_spots` 자체를 관리자 이메일이나 공개 moderation 대상으로
  **자동 연결하지 않는다.**
- 사용자가 장소를 하나 저장했다는 이유만으로 운영자에게 알림이 가지 않는다.

## 2. 공유는 핵심 루프다

사용자의 저장 장소·여행·추억을 외부/SNS 로 공유하고, 그것이 gokoreamate 의
발견·데이터·기억 흐름으로 이어지는 것은 **부가 기능이 아니라 핵심 제품
루프**다. My Places/Share 를 다루는 이후 단계에서는 반드시 다음 두 흐름을
제공한다.

- 외부/SNS 공유
- **gokoreamate 에 공개 장소로 제안**

## 3. 외부 공유와 공개 기여는 같은 동의가 아니다

가장 중요한 줄이다.

- SNS·외부로 공유했다는 사실만으로 그 장소가 **자동으로 공개 데이터가 되지
  않는다.**
- 공개 장소 제안은 **사용자의 명시적 행동과 동의**를 요구한다.

인스타그램에 사진을 올린 사람이 그 장소를 우리 DB 에 넣어 달라고 부탁한 것은
아니다. 두 행동은 다른 뜻이고, 우리가 대신 해석하지 않는다.

## 4. 공개 장소 제안 이후 거치는 것

제안이 들어오면 다음을 거친다.

- 개인정보 보호
- 정확한 개인 위치 보호 (집·숙소 등 사적 좌표를 그대로 공개하지 않는다)
- 중복 장소 검사
- 공개 가능한 정보만 분리 (개인 메모·사진·일정은 따라가지 않는다)
- moderation
- 관리자 알림
- 검증

## 5. 승인 전 자동 공개 금지

- 승인 전 자동 `city_spots` publish **금지**.
- 알림이 갔다는 것은 "확인이 필요하다" 는 뜻이지 승인이 아니다.

## 6. 승인 이후

승인된 공개 장소 후보는 다른 사용자의 Explore · Saved · AI itinerary ·
공유/복사 로 이어질 수 있어야 한다. 승인은 데이터 한 줄을 넣는 일이 아니라
다른 여행자에게 닿게 하는 일이다.

## 7. 이번 작업에서 하지 않은 것

- 공개 장소 제안 UI/API 구현 **안 함**
- My Places 공개 전환 UI 구현 **안 함**
- SNS Share 구현 **안 함**
- `city_spots` 승격 구현 **안 함**

## 8. 확장성만 확보했다

관리자 알림 기반(`044_admin_notification_events`)은 나중에
`public_place_submission` 이벤트를 **migration 을 다시 뜯지 않고** 추가할 수
있도록 `event_type` 을 자유 문자열 축으로 뒀다. 다만 지금 `user_spots` 자체를
알림 대상으로 만들지는 않았다 — 1번 계약 때문이다.

## 신호 의미 (합치지 않는다)

| 신호 | 뜻 | 이메일 알림 |
|---|---|---|
| Saved | 개인 북마크 · personalization 신호 | 없음 |
| Like | 공개 장소 긍정 신호 | milestone digest 후보만 |
| Report | 정보 오류·현장 문제 moderation 신호 | 임계 도달 시 즉시 |
| Helpful | 공유 일정 유용성 | 없음 |
| spot_reactions dislike | legacy 신뢰도 이슈 신호 | 없음 (의미 변경 없음) |
| user_spots | 사용자가 등록한 개인 장소 | **없음** |

Like 에서 Report 를 빼는 점수 같은 것은 만들지 않는다. 서로 다른 축이다.
